# ai-docs-terminal

embeddable AI-терминал для документации: живая консоль прямо на странице доков. юзер пишет по-человечески («создай таблицу users»), AI переводит это в команду, команда **реально выполняется в браузере** — без единого сервера. ошибся — AI объясняет ошибку.

## проблема

- доки cli-инструментов / баз / sdk — статичный текст. юзер копирует команды к себе в терминал, теряет контекст, ошибается, бросает туториал
- интерактивные обучалки (katacoda † 2022, killercoda, instruqt, kodekloud) гоняют **серверные VM** — это дорого (тысячи $/мес для компаний), сложный ops, и это отдельные платформы, а не виджет для собственных доков
- AI-помощь в терминале уже норма в нативе (warp ai, wave, iterm2 ai plugin, jetbrains ai) — спрос доказан, но **web-embeddable версии не существует** (проверено ресерчем 2026-07-11)

## решение

`<DocsTerminal>` — npm-виджет, вставляется в любую docs-страницу за 5 минут:

1. **терминал-ui**: xterm.js — стандарт индустрии (на нём терминалы vs code, jupyterlab, всех cloud shell'ов)
2. **вычисления клиентски, в браузере юзера**:
   - node.js → nodepod (MIT, ~600kb gzipped, старт ~100мс) или browserpod; webcontainers — как опциональный коммерческий бекенд
   - python → pyodide
   - websocket-pty → опциональный серверный бекенд для сценариев, которые в браузер не влазят (docker/k8s)
   - mock-режим → скриптованные команды без вычислений, для лёгких доков
3. **AI-слой**:
   - natural language → команда (ввод через префикс или toggle), с подтверждением перед выполнением
   - объяснение ошибок: exit code != 0 → кнопка «объяснить» → llm получает вывод + контекст
   - «проведи меня по туториалу» — пошаговый режим-агент
   - byok (юзер вставляет свой anthropic/openai ключ, хранится в localstorage) или прокси вендора

**киллер-фича — контекст страницы**: виджет знает, на какой странице доков он стоит (заголовки, mdx-контент), и AI подсказывает команды именно этого раздела. лёгкий rag без инфраструктуры.

## почему именно сейчас (окно)

- MIT-песочницы появились только в 2026 (nodepod, browserpod) — до этого всё упиралось в проприетарную лицензию webcontainers («через сейлзов», без публичных цен). инфраструктурный блокер снят пару месяцев назад
- ai-терминалы стали нормой в нативных приложениях → ожидание юзеров сформировано
- docs-платформы (mintlify, gitbook) наперегонки добавляют AI-фичи → готовый канал дистрибуции и потенциальный покупатель

## аналоги и почему они — не это

| что | почему не то |
|---|---|
| killercoda / instruqt / kodekloud | серверные VM (дорого), отдельные платформы, не виджет |
| codesandbox / stackblitz embeds | встраивают IDE/песочницу кода, не терминал-туториал, без AI-слоя |
| asciinema | только запись/playback, не интерактив |
| jquery terminal, react-terminal-ui и пр. | фейк-терминалы: ни вычислений, ни AI |
| warp / wave / iterm2 ai | нативные приложения, в web не встраиваются |

## аудитория и деньги

- **oss-ядро (MIT)**: виджет + клиентские бекенды → adoption, звёзды
- **платный cloud (потом)**: ai-прокси без byok, **аналитика «где юзеры застревают в туториалах»** (за это docs-команды реально платят), серверные песочницы для docker/k8s-сценариев, приватные туториалы
- покупатели: devtools-компании с cli (базы данных, облака, sdk), edtech, docs-платформы
- из трёх проектов (см. webmcp-devtools, browser-ai-polyfill) — единственный, который продаётся как продукт

## стек

typescript · монорепо pnpm workspaces:
- `docsterm` — vanilla, xterm.js (@xterm/xterm + addons fit/web-links), абстракция Backend
- `@docsterm/backend-nodepod`, `-pyodide`, `-mock`, `-ws`
- `docsterm-react`, `-vue`, `-svelte` — обёртки
- плагины: docusaurus, vitepress, astro starlight, mintlify component
- ai: прямой anthropic/openai api или vercel ai sdk

## риски

- mintlify/gitbook могут построить сами → двигаться быстро, целиться в положение «стандарт-де-факто, который проще купить/встроить, чем повторить»
- в браузере нет docker/k8s → честно ограничить скоуп: node/python/shell-туториалы (а это ~80% devtools-доков); остальное через ws-бекенд
- зрелость nodepod неизвестна (проект свежий) — проверить руками в фазе 0, держать pyodide как запасной первый бекенд
- лицензии: nodepod MIT ок; webcontainers/cheerpx — только как opt-in коммерческие опции

## mvp (2-4 недели)

одна демо-страница: доки вымышленного cli + виджет. флоу: nl-ввод → команда → выполнение в nodepod → ai-объяснение ошибки. плюс плагин для docusaurus. этого хватает для show hn.
