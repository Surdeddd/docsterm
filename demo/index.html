Orbit CLI documentation

Orbit is a fictional command-line tool for deploying tiny apps. Every terminal on this page is live: commands run right here in your browser, and the AI layer can turn a plain-language request into a command. This page itself is the demo of docsterm - an embeddable AI terminal for docs.

AI settings

The AI features are bring-your-own-key: add an Anthropic API key and it stays in your browser's localStorage. Requests go directly from your browser to the Anthropic API. Append ?ai=mock to the URL to try the AI flow with a built-in offline mock.

Getting started

Initialize a project, deploy it, and check its status. Try orbit init, then orbit deploy, then orbit status. Ask the AI with #deploy the app. To see error handling, run orbit destroy and then type explain.

Python tutorial

Orbit automation scripts are written in Python. The terminal below is a real Python environment (Pyodide) running fully client-side. Boot it and try print(2 + 2) or import sys; sys.version.
